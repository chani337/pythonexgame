브라우저에서 바로 실행되는 코딩 문제

파이썬을 설치하지 않아도, 데이터베이스를 깔지 않아도 됩니다.

코드는 브라우저 안에서 실제로 돌아가고, 출력을 바로 채점합니다.

작성한 코드가 서버로 전송되지는 않습니다.

문제 풀어 보기 학습 가이드 읽기

로그인하지 않아도 풀 수 있고, 진도는 브라우저에 저장됩니다.

모든 언어가 실행되는 건 아닙니다.

Python · 알고리즘 · SQL · JavaScript 는 실제로 코드가 돌아갑니다.

Java 와 C 는 문법을 확인하는 객관식 · 빈칸 문제로 제공합니다.

어떻게 돌아가나

서버에 코드를 보내서 실행하는 방식이 아닙니다.

언어별 실행기를 내려받아 개인 컴퓨터의 브라우저 안에서 돌립니다.

자주 묻는 것

정말 무료인가요?

네. 개인이 만든 무료 서비스이고 유료 기능이나 광고가 없습니다.

실행기가 개인 컴퓨터의 브라우저에서 돌아가기 때문에 서버 비용도 거의 들지 않습니다.

로그인해야 하나요?

아니요. 로그인 없이 모든 문제를 풀 수 있습니다.

로그인하면 진도가 계정에 저장돼서 다른 기기에서 이어서 풀 수 있고, 랭킹에 올라갑니다.

로그인 전에 푼 문제는 로그인할 때 계정으로 옮겨집니다.

내가 쓴 코드가 서버로 가나요?

아니요. 코드 실행과 채점이 전부 개인 컴퓨터의 브라우저 안에서 일어납니다.

서버로 보내는 건 “어떤 문제를 풀었다”는 기록뿐입니다.

로그인하지 않으면 그것도 보내지 않습니다.

왜 Java 와 C 는 실행이 안 되나요?

둘은 컴파일이 필요해서 브라우저 안에서 돌리기가 어렵습니다.

지금은 문법을 확인하는 객관식 · 빈칸 문제로 제공하고 있습니다.

실제 컴파일과 실행은 별도 채점 서버가 필요해서 준비 중입니다.

정답은 볼 수 있나요?

대부분의 문제에서 정답 코드와 해설을 볼 수 있습니다.

다만 가장 어려운 챌린지 문제 일부는 아직 해설이 없습니다 — 채워 넣고 있습니다.

휴대폰에서도 되나요?

됩니다. 다만 코드를 많이 입력하는 문제는 키보드가 있는 환경이 훨씬 편합니다.

학습 가이드 읽기와 객관식 문제는 휴대폰에서도 편합니다.

설치할 게 없으니, 바로 열어 보면 됩니다
