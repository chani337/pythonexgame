Pyodide

SQL

SQLite (WASM)

JavaScript

Web Worker

실행기는 한 번 받으면 캐시에 남아 다시 받지 않습니다. CDN 이 막힌 네트워크(학교·회사)에서는 PyQuests 서버의 사본으로 자동 전환합니다.

자주 묻는 것

정말 무료인가요?

네. 개인이 만든 무료 서비스이고 유료 기능이나 광고가 없습니다. 실행기는 당신 브라우저에서 돌아가므로 서버 비용도 거의 들지 않습니다.

로그인해야 하나요?

아니요. 로그인 없이 377문제 전부 풀 수 있습니다. 로그인하면 진도가 계정에 저장돼서 다른 기기에서 이어서 풀 수 있고, 랭킹에 올라갑니다. 로그인 전에 푼 문제는 로그인할 때 계정으로 옮겨집니다.

내가 쓴 코드가 서버로 가나요?

아니요. 코드 실행과 채점이 전부 브라우저 안에서 일어납니다. 서버로 보내는 건 “어떤 문제를 풀었다”는 기록뿐입니다. 로그인하지 않으면 그것도 보내지 않습니다.

왜 Java 와 C 는 실행이 안 되나요?

둘은 컴파일이 필요해서 브라우저 안에서 돌리기가 어렵습니다. 지금은 문법을 확인하는 객관식·빈칸 문제로 제공하고 있고, 실제 컴파일·실행은 별도 채점 서버를 붙여야 해서 준비 중입니다.

정답은 볼 수 있나요?

대부분의 문제에서 정답 코드와 해설을 볼 수 있습니다. 다만 가장 어려운 챌린지 문제 일부는 아직 해설이 없습니다 — 채워 넣고 있습니다.

휴대폰에서도 되나요?

됩니다. 다만 코드를 많이 입력하는 문제는 키보드가 있는 환경이 훨씬 편합니다. 학습 가이드 읽기와 객관식 문제는 휴대폰에서도 편합니다.
