브라우저에서 바로 실행되는 코딩 문제

파이썬을 설치하지 않아도, 데이터베이스를 깔지 않아도 됩니다.

코드는 브라우저 안에서 실제로 돌아가고, 출력을 바로 채점합니다.

작성한 코드가 서버로 전송되지는 않습니다.

문제 풀어 보기 학습 가이드 읽기

로그인하지 않아도 풀 수 있고, 진도는 브라우저에 저장됩니다.

모든 언어가 실행되는 건 아닙니다.

Python · 알고리즘 · SQL · JavaScript 는 실제로 코드가 돌아갑니다.

Java 와 C 는 문법을 확인하는 객관식 · 빈칸 문제로 제공합니다.

어떻게 돌아가나

서버에 코드를 보내서 실행하는 방식이 아닙니다.

언어별 실행기를 내려받아 개인 컴퓨터의 브라우저 안에서 돌립니다.

Python · 알고리즘

Pyodide

CPython 을 WebAssembly 로 컴파일한 것입니다. 진짜 파이썬이라 print 출력도, SyntaxError 도 터미널과 같습니다. numpy · pandas 는 필요한 문제에서만 받습니다.

SQL

SQLite (WASM)

전용 엔진으로 직접 실행합니다. 결과는 컬럼명과 NULL 까지 표로 보여 줍니다. 오라클 문법도 그대로 받습니다 — (+) 외부 조인, NVL, FETCH FIRST.

JavaScript

Web Worker

격리된 워커에서 실행합니다. 학습용 환경이라 네트워크 요청과 브라우저 저장소 접근은 차단되고, 5초가 지나면 끊습니다. 무한 루프로 탭이 멈추지 않습니다.

실행기는 한 번 받으면 캐시에 남아 다시 받지 않습니다.

CDN 이 막힌 네트워크에서는 PyQuests 서버의 사본으로 자동 전환합니다.

실제 문제는 이렇게 생겼습니다

아래 두 개는 사이트에 실제로 있는 문제를 그대로 가져온 것입니다.

Python · 기초

변수 문제 3. 여러 정보 저장하기

이름, 나이, 좋아하는 음식을 각각 변수에 저장하고 출력하세요.

  • 이름은 name
  • 나이는 age
  • 음식은 food
  • 각각 한 줄씩 출력하세요.

작성한 코드

name = "김철수"
age = 20
food = "치킨"
print(name)
print(age)
print(food)

출력 — 기대 출력과 일치하면 통과

김철수
20
치킨
SQL · 기초

SQL 1. 특정 열 조회하기

users 테이블에서 이름과 부서만 조회하세요.

  • 결과는 표로 렌더링됩니다.

작성한 쿼리

SELECT name, dept FROM users;

출력

name | dept
----------------------------------------
김철수 | 개발팀
이영희 | 기획팀
박민수 | 개발팀
최수민 | 디자인팀
정찬희 | 개발팀

공용 컴퓨터에서 안전하게 쓰기

  • 로그인 화면에 "공용 컴퓨터예요 (로그인 유지 안 함)" 선택지가 생겼어요. 학교 컴퓨터실처럼 여러 사람이 쓰는 PC에서 체크하면 탭을 닫는 순간 로그인이 풀려요. (같은 탭에서 새로고침은 그대로 유지되고, 새 탭에서는 다시 로그인해야 해요.)

자주 묻는 것

정말 무료인가요?

네. 개인이 만든 무료 서비스이고 유료 기능이나 광고가 없습니다.

실행기가 개인 컴퓨터의 브라우저에서 돌아가기 때문에 서버 비용도 거의 들지 않습니다.

로그인해야 하나요?

아니요. 로그인 없이 모든 문제를 풀 수 있습니다.

로그인하면 진도가 계정에 저장돼서 다른 기기에서 이어서 풀 수 있고, 랭킹에 올라갑니다.

로그인 전에 푼 문제는 로그인할 때 계정으로 옮겨집니다.

내가 쓴 코드가 서버로 가나요?

아니요. 코드 실행과 채점이 전부 개인 컴퓨터의 브라우저 안에서 일어납니다.

서버로 보내는 건 “어떤 문제를 풀었다”는 기록뿐입니다.

로그인하지 않으면 그것도 보내지 않습니다.

왜 Java 와 C 는 실행이 안 되나요?

둘은 컴파일이 필요해서 브라우저 안에서 돌리기가 어렵습니다.

지금은 문법을 확인하는 객관식 · 빈칸 문제로 제공하고 있습니다.

실제 컴파일과 실행은 별도 채점 서버가 필요해서 준비 중입니다.

정답은 볼 수 있나요?

대부분의 문제에서 정답 코드와 해설을 볼 수 있습니다.

다만 가장 어려운 챌린지 문제 일부는 아직 해설이 없습니다 — 채워 넣고 있습니다.

휴대폰에서도 되나요?

됩니다. 다만 코드를 많이 입력하는 문제는 키보드가 있는 환경이 훨씬 편합니다.

학습 가이드 읽기와 객관식 문제는 휴대폰에서도 편합니다.

설치할 게 없으니, 바로 열어 보면 됩니다
