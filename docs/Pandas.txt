# 파이썬 Pandas 기초

## 1. Pandas란?

Pandas는 **표 형태의 데이터를 쉽고 편리하게 다루기 위한 파이썬 라이브러리**입니다.  
엑셀처럼 생긴 데이터를 읽고, 정리하고, 분석할 때 매우 자주 사용합니다.

쉽게 말하면 Pandas는  
**데이터를 표처럼 다루게 해주는 도구**입니다.

예를 들어,

- 학생 성적표 보기
- 회원 정보 정리하기
- CSV 파일 읽기
- 평균, 합계, 조건 검색하기

같은 작업에 자주 사용합니다.

Pandas는 보통 `pd`라는 이름으로 불러와서 사용합니다.

---

## 2. Pandas 불러오기

```python
import pandas as pd
```

### 설명

- `pandas`는 라이브러리 이름입니다.
- `as pd`는 앞으로 `pandas`를 `pd`라고 짧게 부르겠다는 뜻입니다.

---

## 3. Pandas의 기본 자료형

Pandas에서 가장 많이 사용하는 자료형은 다음 두 가지입니다.

- **Series** : 한 줄짜리 데이터
- **DataFrame** : 표 형태의 데이터

초보자는 보통 **DataFrame**부터 먼저 익히는 것이 좋습니다.

---

## 4. Series 만들기

Series는 **하나의 열(column)처럼 생긴 데이터**입니다.

```python
import pandas as pd

s = pd.Series([10, 20, 30, 40])
print(s)
```

### 실행 결과

```python
0    10
1    20
2    30
3    40
dtype: int64
```

---

## 5. DataFrame이란?

DataFrame은 **행과 열로 이루어진 표 형태의 데이터**입니다.  
엑셀 표와 비슷하다고 생각하면 이해하기 쉽습니다.

```python
import pandas as pd

data = {
    "이름": ["김철수", "이영희", "박민수"],
    "점수": [90, 85, 100]
}

df = pd.DataFrame(data)
print(df)
```

### 실행 결과

```python
    이름   점수
0  김철수   90
1  이영희   85
2  박민수  100
```

---

## 6. 열(Column) 선택하기

DataFrame에서 특정 열만 선택할 수 있습니다.

```python
import pandas as pd

data = {
    "이름": ["김철수", "이영희", "박민수"],
    "점수": [90, 85, 100]
}

df = pd.DataFrame(data)

print(df["이름"])
print(df["점수"])
```

### 실행 결과

```python
0    김철수
1    이영희
2    박민수
Name: 이름, dtype: object

0     90
1     85
2    100
Name: 점수, dtype: int64
```

---

## 7. 여러 열 선택하기

열 이름을 리스트로 묶으면 여러 열을 함께 선택할 수 있습니다.

```python
import pandas as pd

data = {
    "이름": ["김철수", "이영희", "박민수"],
    "점수": [90, 85, 100],
    "반": ["A", "B", "A"]
}

df = pd.DataFrame(data)

print(df[["이름", "점수"]])
```

### 실행 결과

```python
    이름   점수
0  김철수   90
1  이영희   85
2  박민수  100
```

---

## 8. 행(Row) 선택하기

행은 `loc` 또는 `iloc`로 선택할 수 있습니다.

### `loc` 사용하기

```python
import pandas as pd

data = {
    "이름": ["김철수", "이영희", "박민수"],
    "점수": [90, 85, 100]
}

df = pd.DataFrame(data)

print(df.loc[0])
```

### 실행 결과

```python
이름    김철수
점수      90
Name: 0, dtype: object
```

### `iloc` 사용하기

```python
print(df.iloc[1])
```

### 실행 결과

```python
이름    이영희
점수      85
Name: 1, dtype: object
```

---

## 9. 조건으로 데이터 찾기

Pandas에서는 조건을 사용해서 원하는 행만 찾을 수 있습니다.

```python
import pandas as pd

data = {
    "이름": ["김철수", "이영희", "박민수"],
    "점수": [90, 85, 100]
}

df = pd.DataFrame(data)

print(df[df["점수"] >= 90])
```

### 실행 결과

```python
    이름   점수
0  김철수   90
2  박민수  100
```

---

## 10. 새로운 열 추가하기

새로운 열을 만들어서 데이터를 추가할 수 있습니다.

```python
import pandas as pd

data = {
    "이름": ["김철수", "이영희", "박민수"],
    "점수": [90, 85, 100]
}

df = pd.DataFrame(data)

df["합격여부"] = ["합격", "합격", "합격"]
print(df)
```

### 실행 결과

```python
    이름   점수 합격여부
0  김철수   90   합격
1  이영희   85   합격
2  박민수  100   합격
```

---

## 11. 통계값 구하기

Pandas에서는 열의 합계, 평균, 최대값, 최소값 등을 쉽게 구할 수 있습니다.

```python
import pandas as pd

data = {
    "점수": [90, 85, 100, 70, 95]
}

df = pd.DataFrame(data)

print(df["점수"].sum())
print(df["점수"].mean())
print(df["점수"].max())
print(df["점수"].min())
```

### 실행 결과

```python
440
88.0
100
70
```

## 12. CSV 파일 읽기

Pandas는 CSV 파일을 쉽게 읽을 수 있습니다.

```python
import pandas as pd

df = pd.read_csv("student.csv")
print(df)
```

### 설명

- `read_csv()`는 CSV 파일을 읽는 함수입니다.
- 실제 데이터 분석에서는 매우 자주 사용합니다.

## 13. 데이터 기본 정보 확인하기

데이터를 불러오면 먼저 어떤 구조인지 확인하는 습관이 중요합니다.

```python
import pandas as pd

data = {
    "이름": ["김철수", "이영희", "박민수"],
    "점수": [90, 85, 100]
}

df = pd.DataFrame(data)

print(df.head())
print(df.info())
```

### 설명

- `head()` : 위에서부터 몇 개의 행을 보여줌
- `info()` : 열 이름, 데이터 개수, 자료형 등을 보여줌

## 17. 자주 하는 실수

### 1) Pandas를 불러오지 않고 사용하는 경우

```python
df = pd.DataFrame(data)
```

이렇게 쓰면 오류가 날 수 있습니다.  
먼저 Pandas를 불러와야 합니다.

```python
import pandas as pd
```

### 2) 열 하나 선택할 때 대괄호를 잘못 쓰는 경우

```python
print(df["점수"])
```

열 하나를 선택할 때는 열 이름을 문자열로 써야 합니다.

### 3) 조건을 쓸 때 `=`를 사용하는 경우

```python
df[df["점수"] = 90]
```

이 코드는 잘못된 코드입니다.  
비교할 때는 `=`가 아니라 `==`를 사용해야 합니다.

```python
df[df["점수"] == 90]
```

### 4) `and`, `or`를 바로 사용하는 경우

Pandas의 조건식에서는 보통 `and`, `or` 대신  
`&`, `|`를 사용합니다.

```python
df[(df["점수"] >= 80) & (df["점수"] <= 100)]
```

## 18. 한 번에 정리하는 Pandas 예제

```python
import pandas as pd

# 데이터프레임 생성
data = {
    "이름": ["김철수", "이영희", "박민수"],
    "점수": [90, 85, 100]
}

df = pd.DataFrame(data)

# 전체 데이터 출력
print(df)

# 점수 열만 출력
print(df["점수"])

# 90점 이상만 출력
print(df[df["점수"] >= 90])

# 평균 점수 출력
print(df["점수"].mean())
```

### 실행 결과

```python
    이름   점수
0  김철수   90
1  이영희   85
2  박민수  100

0     90
1     85
2    100
Name: 점수, dtype: int64

    이름   점수
0  김철수   90
2  박민수  100

91.66666666666667
```

## 19. 핵심 정리

- Pandas는 표 형태의 데이터를 다루기 위한 라이브러리
- 보통 `import pandas as pd`로 불러옴
- `DataFrame`은 표 형태의 데이터 구조
- 열 선택, 행 선택, 조건 검색이 가능함
- 합계, 평균, 최대값, 최소값 등을 쉽게 구할 수 있음
- `read_csv()`로 CSV 파일을 읽을 수 있음

- 머신러닝 데이터 준비
